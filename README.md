INTRODUCCION

Emancipation game es un proyecto realizado para una materia de la universidad llamada Informatica 2,la cual consta de aprender los fundamentos de C++, programacion orientada a objetos y desarrollo de aplicaciones de escritorio usando el framework QT junto al IDE QT creator.
Es un proyecto completamente de caracter academico, es un desarrollo de aproximadamente 2 semanas totalmente individual hecho por mi.
Las teconologias princpiales usadas son C++ en el IDE Qt creator junto al framework QT usado para aplicar interfaz grafica en escritorio.

PASOS PARA EJECUTAR EMANCIPATION GAME

1. Descargar el archivo emancipation.rar que se encuentra el la carpeta "Executable" en el repositorio de github

2. Una vez descargado extraer el todo el archivo en la carpeta que deseemos

3. Abrir la carpeta emancipation

4. Buscar en la carpeta el archivo Emancipation.exe y ejecutarlo como administrador

5. El archivo normalmente avisa de una posible vulneracion de virus, pero es porque el juego fue hecho totalmente desde 0 con conocimientos aprendidos en un semestre, nada profesional.
